# AI Penetration Testing Agent

This is my AI-driven penetration testing agent project for my Artificial Intelligence for Cybersecurity course. The agent was designed to autonomously test OWASP Juice Shop for common web vulnerabilities.

## Technologies
- Python
- GPT-4o
- Docker
- LiteLLM
- OWASP Juice Shop

## Features
- Automated SQL injection testing
- Cross-Site Scripting (XSS) testing
- API fuzzing
- ReAct-based agent workflow
- Automated penetration testing report generation

## Results
The agent successfully identified and exploited a SQL injection vulnerability to bypass authentication in the OWASP Juice Shop environment.

## Project Structure
- `agent/` - AI agent source code and security testing tools
- `reports/` - Generated penetration testing report
- `writeup_assets/` - Project screenshots and testing results 
- `DESIGN.md` - System design documentation
- `WRITEUP.md` - Final project writeup
